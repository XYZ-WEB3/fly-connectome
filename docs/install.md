# Установка — по шагам

Проверено на Windows 11, Python 3.12, видеокарте NVIDIA RTX 4070 Laptop.

## Что нужно

| | минимум | заметка |
|---|---|---|
| система | Windows 10 / 11, 64 бит | на Linux код тоже должен работать, но `.bat`-файлы — только для Windows |
| видеокарта | NVIDIA с драйвером не старше пары лет | без неё мозг считается на процессоре в сотни раз медленнее |
| память | 16 ГБ | рендер ролика в 5 процессов берёт 4–6 ГБ |
| диск | ~15 ГБ | PyTorch ~5 ГБ, модель Whisper ~3 ГБ, данные ~0.2 ГБ |
| интернет | нужен при установке | потом всё работает без сети |

## Шаг 1. Python

1. Открой [python.org/downloads](https://www.python.org/downloads/) и скачай **Python 3.12** для Windows.
2. При установке на первом экране поставь галочку **«Add python.exe to PATH»**. Это важно.
3. Нажми «Install Now».

## Шаг 2. Проект

- Без git: на странице репозитория зелёная кнопка **Code -> Download ZIP**, распакуй, например, в `C:\fly`.
- С git: `git clone <адрес репозитория> C:\fly`.

Лучше путь без пробелов и без русских букв.

## Шаг 3. Установка одной кнопкой

Открой папку проекта и дважды щёлкни **`setup\install.bat`**. Он:
1. создаст своё окружение `.venv` внутри папки (в систему ничего не ставится);
2. поставит PyTorch с поддержкой видеокарты (~3 ГБ — это самый долгий шаг);
3. поставит остальные пакеты из `requirements.txt`;
4. скачает данные коннектома FlyWire и модели Shiu et al. (~135 МБ) — `setup\get_data.py`;
5. запустит проверку `setup\check.py`.

В конце должно быть «Всё готово». Последний шаг проверки — 1 секунда жизни мозга мухи.

## Шаг 4. Первый ролик

Перетащи любой видеофайл на **`Муха-ролик.bat`**. Нет своего — сделай тестовый:

```bat
.venv\Scripts\python.exe stream\testclip.py
```

Он появится как `stream\testclip.mp4` — его и перетащи. Готовое видео будет в папке `готово`.

## Если что-то не так

| что видишь | что делать |
|---|---|
| «Не найден Python» | Python не стоит или не отмечена галочка «Add python.exe to PATH». Переустанови Python с галочкой |
| `python` открывает Microsoft Store | Это заглушка Windows. Поставь Python с python.org (шаг 1) |
| ошибка на шаге PyTorch | Проверь интернет и место на диске, запусти `install.bat` ещё раз — он продолжит |
| `check.py`: «видеокарта NVIDIA с CUDA не найдена» | Обнови драйвер NVIDIA (сайт NVIDIA или GeForce Experience) и перезагрузи компьютер |
| `check.py`: «нет данных коннектома» | Запусти `.venv\Scripts\python.exe setup\get_data.py`. Если не качается — проверь, открывается ли github.com |
| «контрольная сумма не совпала» | Файл в источнике изменился или скачался криво. Удали его и запусти `get_data.py` снова |
| `рендер MuJoCo: НЕТ` | Обнови драйвер видеокарты. На ноутбуке с двумя видеокартами разреши Python использовать NVIDIA |
| рендер падает «Could not allocate memory» | Мало свободной памяти: закрой браузер и тяжёлые программы или уменьши `--workers` (в окне — «процессы») |
| «быстрое ядро мозга не собралось» | Мозг работает старым путём (медленнее). Обычно помогает обновить драйвер NVIDIA |
| режим «по смыслу речи» долго стартует | В первый раз скачивается модель Whisper (~3 ГБ). Без этого режима: `--meaning off` |

## Вручную (если не хочешь .bat)

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe setup\get_data.py
.venv\Scripts\python.exe setup\check.py
```

Для сверки с исходной моделью на Brian2 (`check_brian2.py`) нужен ещё `requirements-extra.txt`.
